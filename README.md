# bonsai-2-27B-tests
Bonsai 2 27B is a flagship, ultra-compact multimodal language model released by PrismML on September 17, 2026. It is a ternary-quantized compression of the Qwen3.8 27B model, designed to bring 27B-class reasoning, coding, vision, and agentic capabilities to local consumer hardware like PCs and high-end smartphones
